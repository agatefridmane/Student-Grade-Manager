I built a Java command-line program that stores, displays, and updates student grades. Each student record contains a first name, a surname, and grades for Math, Sport, and Programming.
- Create saves five sample student records to Students.dat.
- View reads the saved records and displays them in a numbered table.
- Calculate updates all three grades for the student selected by row number. It writes the records to a temporary file, then replaces the original file with the updated version.
This project gave me practice defining a Student class, saving and loading Java objects through serialization, and updating individual records in a file.
